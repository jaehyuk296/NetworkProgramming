# 🕵️‍♂️ Java Network Davinci Code (다빈치 코드 온라인)
자바(Java) 소켓 통신을 기반으로 구현한 실시간 멀티플레이어 보드게임 **'다빈치 코드'** 프로젝트입니다.
중앙 서버를 통해 다수의 클라이언트가 접속하여 대기실(로비)에서 매칭하고, 게임 방에서 실시간으로 추리 대결을 펼칠 수 있습니다.

## 🛠️ 개발 환경 (Tech Stack)
* **Language**: Java (JDK 1.8 이상)
* **GUI**: Java Swing (AWT)
* **Network**: Java Socket (TCP/IP), Object Serialization
* **IDE**: Eclipse / IntelliJ / VS Code

## ✨ 주요 기능

### 1. 네트워크 시스템
* **멀티 스레드 서버**: `ClientHandler` 스레드를 통해 다수의 클라이언트 동시 접속 처리
* **프로토콜 통신**: `Message` 객체 직렬화를 통한 안정적인 데이터 패킷 교환
* **예외 처리**: 유저 강제 종료 시 자동 패배 처리 및 게임 지속성 유지 (서버 안정성 확보)

### 2. 게임 로직
* **자동 정렬 시스템**: 타일 수령 시 '숫자 오름차순' + '색상 우선순위(검<흰)' 자동 정렬
* **조커(Joker) 시스템**: 조커 획득 시 플레이어가 원하는 위치에 삽입하여 심리전 유도
* **턴(Turn) 관리**: 시간 제한 및 턴 넘기기, 연속 추리 기능 구현
* **멀티 룸(Multi-Room)**: 여러 개의 게임 방을 생성하고 독립적으로 게임 진행 가능

### 3. 사용자 인터페이스 (GUI)
* **CardLayout**: 로그인 -> 로비 -> 대기방 -> 게임 화면의 매끄러운 화면 전환
* **실시간 채팅**: 대기실 및 게임 중 유저 간 실시간 채팅 지원
* **서버 모니터링**: 관리자용 서버 GUI를 통해 패킷 송수신 로그 및 접속자 현황 실시간 확인

## 🚀 실행 방법 (How to Run)

### 1. 설정 파일 (server.txt)
* 서버와 클라이언트가 통신하기 위해 프로젝트 최상위 폴더에 server.txt 파일이 있어야 합니다. (없을 경우 기본값 localhost 9999로 동작합니다.)

* 형식: [IP주소] [포트번호]

* 127.0.0.1 9999
* 다른 컴퓨터와 연결 시 127.0.0.1 대신 서버 컴퓨터의 실제 IP 주소를 입력하세요.

### 2. 서버 실행
* server.GameServer.java를 실행합니다.

* 관리자 로그 창이 뜨면 서버 구동 완료입니다.

### 3. 클라이언트 실행
* client.GameClient.java를 실행합니다.

* 닉네임을 입력하고 로그인합니다.

* (테스트 시) 클라이언트를 여러 개 실행하여 서로 다른 닉네임으로 접속합니다.

## 🎮 게임 규칙
* 0~11까지의 숫자 타일(흑/백)과 조커(-)를 나눠 갖습니다.

* 타일은 작은 숫자가 왼쪽, 같은 숫자면 검은색이 왼쪽에 오도록 자동 정렬됩니다.

* 자신의 턴에 타일을 하나 가져오고, 상대방의 타일 하나를 지목하여 숫자를 맞춥니다.

* 정답: 해당 타일이 공개되고, 계속 공격하거나 턴을 넘길 수 있습니다.

* 오답: 방금 가져온 내 타일을 공개하고 턴이 넘어갑니다.

* 상대방의 모든 타일을 먼저 공개시키는 사람이 승리합니다.
